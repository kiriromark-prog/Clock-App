# Tkinter Digital Clock & Stopwatch

A clean, modern desktop time-tracking application built with Python and Tkinter. 

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## Features
* **Clock Tab:** Displays the current local time with a toggle for 12-hour or 24-hour formats.
* **Stopwatch Tab:** Fully functional stopwatch with millisecond precision, start, stop, and reset features.
* **Non-Blocking UI:** Built using Tkinter's `after()` loop method to ensure the interface never freezes.
* **Dark Mode UI:** Styled with a comfortable dark background and high-visibility neon/white text.

---

## Prerequisites
Make sure you have **Python 3** installed on your system. Tkinter comes pre-installed with standard Python distributions on Windows and macOS. 

*(Linux users may need to install it via package manager, e.g., `sudo apt-get install python3-tk`)*
